INSTALADOR NO NAVEGADOR

Firmware, apps e jogos
para o Galaxy Fit3.

Tudo roda no seu navegador. Nada é enviado para nenhum servidor; a conexão vai direto do navegador para o relógio pelo Web Serial.

Abra este site em HTTPS (ou um arquivo local) no Chrome ou Edge atual, em um PC. É preciso o navegador suportar Web Serial.
01

Conecte o relógio

Pareie o Galaxy Fit3 com este computador no Bluetooth do Windows primeiro, e feche o Galaxy Wearable.

02

Escolha o firmware

SEU ARQUIVO

Firmware próprio

Um pacote FWD (.bin). Verificado por inteiro antes de qualquer envio; sem assinatura do projeto (verificação estrutural só).

Atenção: risco de danificar o relógio

Só o Galaxy Fit3 SM-R390 com R390XXU0AZA3 é suportado. Gravar firmware pode deixar o relógio em ciclo de reinicialização ou inutilizável.

Firmware verificado

02

Escolha um app .f3a

Apps leves (jogos, utilitários) rodam dentro do launcher "Meus apps" do relógio, sem regravar o firmware. Precisa de um firmware com a loja instalada.

App verificado

02

Escolha um jogo J2ME (.jar)

Instala o player J2ME (na primeira vez) e o jogo. Precisa de um firmware com a loja instalada. Jar de até 1,5 MB.

Jogo verificado

Antes de instalar
  • O relógio precisa estar ligado e com Bluetooth acessível. Feche outros programas conectados a ele.
  • Confira a versão em Configurações > Sobre > Informações do software, e carregue acima de 50%.
  • O Web Serial deste navegador só abre o canal que o Windows já criou para o relógio pareado; se a porta serial não existir, nenhuma ferramenta neste navegador consegue gravar.
