Ponte Web do Fit3 desconectado

Pareie o relógio com o PC antes. O modo navegador atende os pedidos de página que o relógio grava no arquivo /user/web_req.txt e devolve em /user/web_page.txt. Mantenha esta página aberta e o relógio perto.
Game Boy: enviar jogo (ROM) (o emulador do relógio lê /user/gb.gb; use um jogo seu, .gb ou .gbc)
Controle pelo teclado e mouse do PC (funciona mesmo sem o relógio conectado; o quadro também vai para o relógio quando ele está conectado)
Clique na imagem para clicar; roda do mouse rola; digite normalmente (Enter, Backspace, Tab, setas, PgUp/PgDn, Ctrl+V cola). A imagem é o que aparece no relógio.
Limite de transferência de arquivos
O watch grava só em /user, limite de 16 MiB por arquivo. Firmware .bin (~18 MB) não passa por aqui: use o Fit3 Web Flasher (Web Serial) ou OTA. Este canal serve para ROM de Game Boy (.gb/.gbc), saves e arquivos pequenos do usuário.
